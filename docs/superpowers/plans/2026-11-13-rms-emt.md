# Sequential RMS–EMT Implementation Plan

**Goal:** Reproducible engineering demonstration using installed PSS/E and PSCAD.
**Architecture:** Isolated simulator worker processes exchange versioned JSON;
physical conversion and result processing remain usable without either simulator.
**Tech stack:** Python 3.11, numpy, matplotlib, pytest, psspy/pssarrays, mhi.pscad.
**Spec:** ../../design.md

## Constraints and review focus

- Exact 230 kV / ±100 MVAr / 150 ms demonstration defaults; configurable inputs.
- Real documented APIs; fail closed on unsupported/missing data and simulator errors.
- Positive-sequence balanced equivalent; explicit current and Q orientation.
- Never call test signals or analytical estimates simulator output.
- Prevent stale outputs, wrong bases, polar impedances, misaligned time and fabricated dynamic comparisons.

## Tasks

- [x] Conversion/configuration: tests for per-unit conversion, E=V+ZI, current limits and invalid inputs; implement physics.py and config.py.
- [x] PSS/E: generate and solve two-bus case, validate convergence, extract ASCC data and boundary operating point with metadata; implement psse_worker.py.
- [x] PSCAD: construct native averaged terminal model through documented APIs, transfer parameters, run, preserve logs/raw files; implement pscad_worker.py.
- [x] Processing: test balanced waveform RMS/Q, fault duration, malformed output; implement results.py and reporting.py.
- [x] Orchestration: implement CLI, isolated subprocess timeouts, unique run directories, manifests, missing-input templates and instructions.
- [x] Verify: run offline tests and real simulations; inspect figures; independent final review and fix material findings.

Execution ruling: work in the supplied empty workspace. No existing repository or
user files require an isolated worktree. The detailed user request authorizes the
implementation and routine engineering defaults; no additional approval gate.

Validation completed: two native simulator cases, 15 physical checks each, 15 offline tests, and a passing 5-to-2.5 microsecond EMT sensitivity check. See docs/VALIDATION.md. The averaged terminal model and absent dynamic RMS model remain explicit scope limits.
